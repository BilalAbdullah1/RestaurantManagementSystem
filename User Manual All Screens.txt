# 📘 VOKE Solutions — School Management System (SMS)
# Complete User Manual — Screen-by-Screen Guide

---

> **System Name:** VOKE Solutions SMS  
> **Type:** Multi-Tenant School Management System  
> **Roles:** Admin, Teacher, Staff, Parent, Student  
> **Architecture:** React + .NET Core API + SQL Server  

---

## 🔐 PHASE 1: AUTHENTICATION (Login Flow)

### Screen 1: Sign In (`/signin`)
**Purpose:** System entry point for all users.

**Key Features:**
- Email & Password login
- Role-based redirection after login:
  - **Admin** → Admin Dashboard
  - **Parent** → Parent Dashboard
  - **Student** → Student Dashboard
  - **Staff/Teacher** → Staff Dashboard
- "Forgot Password?" link → takes you to Password Recovery screen
- "Sign Up" link → takes you to Registration screen

**Flow:** After successful login → System checks your role → Auto-redirects to your dashboard.

---

### Screen 2: Sign Up (`/signup`)
**Purpose:** New user registration (typically admin-invited).

**Key Features:**
- Register a new account with credentials
- After registration → Redirect to Sign In

---

### Screen 3: Forgot Password (`/ForgotPassword`)
**Purpose:** Password recovery for locked-out users.

**Key Features:**
- Enter registered email
- System sends a password reset link to email
- **Flow:** Enter email → Receive link → Click link → Opens Reset Password screen

---

### Screen 4: Reset Password (`/ResetPassword`)
**Purpose:** Set a new password using the recovery link.

**Key Features:**
- Enter new password & confirm
- After successful reset → Redirect to Sign In

---

### Screen 5: Public Admission Portal (`/PublicAdmissionPortal/:tenantId`)
**Purpose:** Public-facing form for parents to submit admission applications online. **No login required.**

**Key Features:**
- Parents fill out student information, guardian details, and class preference
- Each school (tenant) has its own unique portal link
- Submitted applications appear in the Admissions CRM (admin side)
- **Flow:** Parent fills form → Submission saved → Admin reviews in Admissions CRM

---

## 📊 PHASE 2: DASHBOARDS (Role-Based Home Screens)

### Screen 6: Admin Dashboard (`/dashboard`)
**Purpose:** Central command center for Admin users. Shows a bird's-eye view of the entire school.

**Key Features:**
- **KPI Summary Cards:** Total students, total staff, fee collection, attendance rate
- **Attendance Chart:** Visual graph of today's student attendance
- **Fee Collection Overview:** Revenue chart with monthly trends
- **Recent Admissions:** Latest enrolled students
- **Quick Action Buttons:** Jump to Student Directory, Fee Challans, Staff Directory, etc.
- **Notices/Announcements:** Latest noticeboard items
- **Calendar Events:** Upcoming school events

**Flow:** This is the Admin's landing page. From here, navigate to any module via the sidebar.

---

### Screen 7: Parent Dashboard (`/parent-dashboard`)
**Purpose:** A parent's personalized view of their child's school activity.

**Key Features:**
- **Child's Attendance Summary:** Present/Absent stats
- **Fee Status:** Outstanding dues, last payment info
- **Exam Results:** Latest marks/grades
- **Homework Status:** Pending/Submitted assignments
- **Recent Notices:** School announcements
- **Quick Actions:** Apply for Leave, View Fee History, View Report Card

**Flow:** Parents land here after login. They can view their child's info and use quick action links.

---

### Screen 8: Student Dashboard (`/student-dashboard`)
**Purpose:** A student's personal academic hub.

**Key Features:**
- **My Attendance:** Attendance percentage & calendar heatmap
- **My Results:** Latest exam scores and grades
- **My Timetable:** Today's class schedule
- **Homework:** Pending assignments
- **Notices:** School announcements
- **Quick Actions:** View assignments, take online exams

**Flow:** Students land here. They can view their academic data and access assignments/tests.

---

### Screen 9: Staff Dashboard (`/staff-dashboard`)
**Purpose:** A teacher/staff member's personal workspace.

**Key Features:**
- **My Attendance:** Personal attendance record
- **My Timetable:** Today's teaching schedule
- **Leave Balance:** Remaining leave days
- **Quick Actions:** Mark attendance, view timetable, apply for leave
- **Notices:** School announcements

**Flow:** Staff/Teachers land here. From here, navigate to their relevant modules.

---

## 📢 PHASE 3: NOTICEBOARD

### Screen 10: Notice Board (`/Noticeboard`)
**Purpose:** School-wide announcement board visible to all roles.

**Key Features:**

## 👨‍🎓 PHASE 5: STUDENTS MODULE

### Screen 25: Student Directory (`/students`)
**Purpose:** Master list of all enrolled students.

**Key Features:**
- **KPI Stat Cards:** Total students, active, inactive, by gender
- **Data Table:** Searchable, sortable, filterable list of all students
- **Search:** Global search by name, roll number, class
- **Filters:** Filter by class, section, status, gender
- **Profile Drawer:** Click a student → Opens side panel with full profile (photo, contact, academic info)
- **Action Menu (per row):** View Profile, Edit, Medical Records, Transfer Certificate, Deactivate
- **Add New Student:** Button to register a new student
- **Export:** CSV and PDF export of student data
- **Pagination:** Rows per page selector

**Flow:** View all students → Click to see profile → Use actions to manage individual students.

---

### Screen 26: Parent Directory (`/parents`)

- **Data Table:** All parents with name, contact, linked students

**Flow:** View parents → Click to see which children they're linked to.

### Screen 27: Admissions CRM (`/AdmissionEnquiries`)

**Key Features:**

           │
STEP 9:  Sections → Create sections under each class (A, B, C)
           │
STEP 10: Subjects → Define all subjects (English, Math, Science, etc.)
           │
STEP 11: Assign Subject to Class → Map subjects to each class
           │
STEP 12: Staff Directory → Add all teachers and staff members
           │
STEP 13: Class Timetable → Create weekly timetable for each class

           │

           │

           │
STEP 16: Parent Directory → Parents auto-created with student registration
           │
STEP 17: Fee Setup → Define fee types
           │

           │

           │
STEP 20: Fee Challans → Generate monthly invoices
           │
STEP 21: Chart of Accounts → Set up accounting structure
           │
STEP 22: Daily Operations Begin:
           │
           ├── Student Attendance → Daily marking
           ├── Staff Attendance → Daily marking

           ├── Notices → Post announcements
