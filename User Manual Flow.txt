# 🔗 VOKE Solutions SMS — Complete Operational Flow Guide & User Manual
# Step-by-Step Chain: "What Comes After What?"

---

> **System:** VOKE Solutions — School Management System (SMS)  
> **Architecture:** Clean Architecture .NET 10 Web API + React 19 Vite TypeScript + TailwindCSS  
> **Purpose:** This guide shows the exact sequence of operations to follow when setting up, administering, and operating the SMS.  
> Every step tells you: **Where to Navigate → What to Do (All Scenarios & Forms) → Validations & Edge Cases → Backend APIs & Tables → What Happens Next.**  
> Includes a **100% interconnected, human-readable dummy dataset (Zero GUIDs!)** so you can easily understand, test, and implement the entire system flow.

│       • Teacher or Staff → Staff Dashboard (/staff-dashboard)    │
